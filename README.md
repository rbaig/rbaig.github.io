# rbaig.github.io

This is the main repository for my personal GitHub Pages site, hosted at [rbaig.github.io](https://rbaig.github.io/).

The default page (`index.html`) is a hand-maintained list of links to the websites of my projects.

## Adding a project
Add a new `<li>` entry to the list in `index.html` and push to `main`.

## Repository Structure
* `index.html` — The landing page listing the project websites.
* `.github/workflows/deploy.yml` — GitHub Actions workflow that deploys the site to GitHub Pages on every push to `main`.
